# Python Socket Programming in 10 Simple Steps

This folder contains the source code for the blog post:  
**"Python Socket Programming in 10 Simple Steps"**

## Files

- `server.py` – A simple Python socket server that listens for client connections.
- `client.py` – A Python client that connects to the server and exchanges messages.

## How to Run

1. Open a terminal and navigate to this folder.
2. Start the server: python3 server.py
3. In a separate terminal window, run the client: python3 client.py
4. You should see the server print a message received from the client, and the client display the server’s response.
