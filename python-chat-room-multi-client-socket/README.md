# Building a Simple Python Chat Room with Multi-Client Socket Programming

A simple chat room built with Python sockets and threading. Multiple clients can join, set usernames, and chat in real time.

## Files

- `server.py` – Multi-client chat server.
- `client.py` – Interactive chat client.

## How to Run

1. Open a terminal and start the server: python server.py
2. In separate terminals, run the client: python client.py
3. Enter a username when prompted. Type messages to chat. Type `exit` to leave.

## Features

- Multiple clients supported
- Usernames and message formatting
- Real-time message broadcasting
